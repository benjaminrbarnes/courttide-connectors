# Contributing

Contributions are welcome. Read [AGENTS.md](AGENTS.md) and the
[new connector guide](docs/NEW-CONNECTOR.md) before starting.

Use synthetic data in this repository. Keep real configurations and recorded
responses outside it. Describe changes with platform names only.

Discovery and live checks share the request ceilings in [AGENTS.md](AGENTS.md)
across all workers and iterations for the same connector and upstream target.

Run `npm run check` before opening a pull request.
